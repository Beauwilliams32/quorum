# Roadmap

## Verified now

- Loopback cockpit, terminals, missions, artifacts, and memory routing.
- macOS process and `launchd` inventory with normalized ownership classes.
- Preview and confirmation for permitted user-process signals.
- Standing-job state, retries, suspension, history, and resource defaults.
- Full-bleed Three.js city with real-state entities and list fallback.
- HQ: an org chart of agents with managers, monthly budgets (hard stop),
  heartbeats and approvals; channels and DMs where an @mention hands out a
  ticket; signed agent replies with evidence cards; a hash-chained audit log;
  routines that open recurring tickets; search across the whole message
  history; the HQ dashboard view, the HQ CLI commands and `quorum top`.

## Acceptance in progress

- Native Linux `systemd` and Windows Services/Task Scheduler host testing.
- Signed least-privilege helpers for protected host operations.
- Authenticated Tailscale gateway with device and replay evidence.
- Provider cost reconciliation against the $25 daily ceiling.
- HQ runs in an isolated git worktree per ticket. Today a run works in the
  project room's own checkout, exactly like a mission dispatch.
- HQ agents on harnesses beyond Claude Code and Codex. They need a structured,
  non-interactive adapter first; until then HQ says so and refuses them.
- Several companies per cockpit, and company templates exported and imported
  as files.
- Search inside archived logs (`archive/`). Today search reads the live
  `messages.jsonl` only.

Roadmap items are not presented as shipping capabilities.
