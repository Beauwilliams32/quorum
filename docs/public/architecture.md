# Architecture

Quorum is a local-first control plane. Its Node server binds to loopback,
collects secret-free operational state, and serves conventional 2D views plus a
Three.js city. Projects become buildings; real agent lifecycle records and
normalized process records become selectable characters and worker units.

The browser receives bounded snapshots and events, not credentials or complete
terminal transcripts. Process actions are limited by ownership classification
and use preview plus explicit confirmation. Protected operations are outside the
unprivileged server. Unsupported platform capabilities are reported rather than
simulated.

Obsidian is the durable memory route. Quorum indexes bounded, redacted metadata
for Claude, Codex, project, terminal, and vault artifacts, then opens raw sources
only when requested. Mission notes are written only under the configured Quorum
missions folder.

macOS is the currently accepted native host. Linux and Windows adapters are
present for continued test work but remain native-host acceptance pending.
